# EverStarine 个人学术主页

本文用于理解公开学术源码的托管布局、预览与 PDF 更新入口。保留原因是两个托管版本可能不同，需避免误认同步状态；布局、字段或托管方案改变时更新说明，已无后续使用价值时清理。

个人学术主页的独立源码仓库，首次发布于 2026-10-11。

## 备份内容

`dist/` 包含可直接托管的网站文件：

- 首页、个人介绍、主要研究、教学计划、参与活动、学术发表、工程项目和留言板框架；研究方向及当前、历年课程资料设有独立子页面。

- 分析学 3 卷、代数学 5 卷，以及 6 份教学 PDF，共 14 份 PDF；保留在线阅读和下载入口。教学资料包括线性代数 I、II 教材及第 01–04 次习题课讲义，II 教材按历史课程独立归档。
- 首页展示轮换引语，以及从研究、当前课程和活动数据生成的“近况与记录”摘要；研究尚无具体进展记录时展示研究方向概览，活动按实际日期取最新记录。
- 个人介绍包含学习经历、单位与联系方式；学术邮箱支持点击复制，邮箱与 GitHub 入口仅在个人介绍展示。arXiv 作者 ID 和 ORCID 研究者 ID 保留空位。
- 研究栏目包含奇点与分层理论、算子代数、AI 与形式化；教学栏目区分当前与历年课程，包含课表、大纲、讲义、参考书和试卷空位；活动栏目展示会议和访问记录，支持分类筛选。
- 主导航下划线滑动，发表、教学、活动分类底板带斜切边移动，切换内容轻滑入场；遵循系统减少动态效果偏好。

网站采用静态 HTML、CSS 和 JavaScript，页面之间使用 hash 路由。无需构建、数据库或 ChatGPT 账号即可在其他静态托管平台运行；字体使用 Google Fonts，字体服务不可用时使用本地后备字体。

## 当前用途与同步目标

本仓库已公开，并通过 GitHub Pages 提供独立于 ChatGPT 订阅的网站访问。

GitHub Pages：<https://everstarine.github.io/academic-homepage/>

ChatGPT Sites：<https://wuling-academic-study-1011.pretty-grass-6439.chatgpt.site/>。

本批次同步目标为 ChatGPT Sites 与 GitHub Pages 使用同一份当前网站文件，并同步 GitHub `main` 源码副本。本说明记录同步范围；发布是否完成以相应托管服务状态和线上文件核验为准。

`main` 分支保留 `dist/` 源码与资源；`gh-pages` 分支将相同文件放在根目录供 Pages 发布，并使用 `.nojekyll` 保持静态文件原样。GitHub 自动发布推送到 `gh-pages` 的更新；只修改 `main` 或本地文件不会更新线上页面。

本地项目的日常修改先检查并积累成批，按用户对该批次的要求更新所需托管目标。设立原因：用户希望集中更新，且源码备份、Pages 和 Sites 可以分别维护。失效条件：用户改变发布约定或托管布局时，替换对应流程。

本仓库不包含 Sites 托管标识、本地工作记录、部署凭据、书籍 TeX 源文件或重复压缩包。

设立原因：这些文件不属于当前公开网页，分离可减少泄露与无关上传。失效条件：公开范围经用户确认调整时更新文件范围；认证方式变化时采用新的凭据保护方案。

## 预览与恢复

下载或克隆本仓库后，使用任意静态文件服务器，以 `dist/` 为网站根目录即可预览。也可以将 `dist/` 内的全部文件连同原有目录结构上传到静态网站托管服务。

PDF 位于 `dist/assets/pdf/`，卷册信息和下载地址定义在 `dist/books.js`。更新 PDF 时需同步检查该文件中的页数、文件大小和日期。

设立原因：页面元信息与 PDF 分别保存，替换文件不会自动更新介绍。失效条件：元信息改为可靠自动生成或字段接口改变后，采用新流程。

页面内容与交互位于 `dist/app.js`，入口和样式分别位于 `dist/index.html`、`dist/styles.css`。栏目数据分开维护：

- `dist/research.js`：研究方向介绍与研究进展集合；当前进展集合为空，首页使用方向概览。
- `dist/teaching.js`：当前课程、历年课程、课表、教学大纲和资料索引；教学 PDF 放在 `dist/assets/pdf/teaching/`，历年课程使用独立课程目录。
- `dist/activities.js`：会议与访问记录，按实际活动日期排序。
- `dist/books.js`：分析学和代数学的分卷信息。
